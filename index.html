Upload a .csv file or paste CSV text. First row must be headers:

EmployeeID, EmployeeType, Company, Surname, FirstName, MI, Department, DepartmentOther, Position, TrainingType, TrainingTypeOther, Training, OutsourcedSpeaker, SpeakerOther, Trainor, Date, Hours, ActualScore, ExpectedScore, Remarks

Required: EmployeeType (Newly hired or Existing employee), Company, Surname, FirstName, Department, TrainingType, ActualScore, ExpectedScore. Company must match the dropdown list. If Training (the title) is left blank, it is set equal to the training type. Position is optional but must match a position saved in the Position tab. Passed/Failed is computed automatically (70% existing, 50% newly hired); any Status column is ignored. If the speaker isn’t on the list, it’s saved under “Others”. Certificate pictures can’t be bulk uploaded; add them afterward with Edit. In Excel, use Save As → CSV.
